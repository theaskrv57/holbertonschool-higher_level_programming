# Python Input / Output & JSON Handling

This project focuses on file handling, JSON serialization, and data persistence in Python.

## Project Overview

The tasks in this directory explore:

- Reading and writing text files
- Appending content to files
- Working with JSON format
- Serializing Python objects to JSON
- Deserializing JSON into Python objects
- Saving and loading data from files
- Object-to-dictionary conversion
- Generators and basic statistics
- Implementing Pascal’s Triangle algorithm

The goal of this project was to understand how Python handles file systems and structured data storage.

## Files Description

- 0-read_file.py: Reads a text file and prints its content.
- 1-write_file.py: Writes text to a file.
- 2-append_write.py: Appends text to an existing file.
- 3-to_json_string.py: Converts Python object to JSON string.
- 4-from_json_string.py: Converts JSON string to Python object.
- 5-save_to_json_file.py: Saves Python object to JSON file.
- 6-load_from_json_file.py: Loads JSON file into Python object.
- 7-add_item.py: Adds arguments to a list stored in a JSON file.
- 8-class_to_json.py: Converts class instance to dictionary.
- 9-student.py / 10-student.py / 11-student.py: Implements student class with serialization methods.
- 12-pascal_triangle.py: Generates Pascal’s triangle.
- 100-append_after.py: Inserts text after a specific string in a file.
- 101-generator.py / 101-stats.py: Implements generator-based processing and statistics.
