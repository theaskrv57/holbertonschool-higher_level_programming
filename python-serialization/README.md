# Python Serialization

This project focuses on data serialization and deserialization techniques in Python using multiple formats.

## Project Overview

The tasks in this directory explore:

- Converting Python objects into JSON format
- Using Pickle for object serialization
- Working with CSV files
- Parsing and generating XML data
- Data persistence techniques

The objective of this project was to understand how structured data can be stored, transmitted, and reconstructed across different formats.

## Files Description

- task_00_basic_serialization.py: Implements JSON serialization and deserialization.
- task_01_pickle.py: Demonstrates object persistence using Pickle.
- task_02_csv.py: Reads and writes CSV files.
- task_03_xml.py: Parses and generates XML data.

## Technologies Used

- Python 3
- JSON
- Pickle
- CSV
- XML

## Key Concepts Practiced

- Data encoding formats
- Object persistence
- Secure vs insecure serialization (Pickle awareness)
- Structured data exchange
- File-based data storage
