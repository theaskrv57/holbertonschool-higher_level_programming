# Python Exceptions

This project focuses on understanding and handling exceptions in Python to build more robust and reliable programs.

## Project Overview

The tasks in this directory cover:

- Handling runtime errors using try/except
- Catching specific exception types
- Raising custom exceptions
- Writing safe function implementations
- Managing division errors
- Error handling with custom messages
- Working with stderr output

The goal of this project was to develop defensive programming skills and understand how to write fault-tolerant Python code.

## Files Description

- 0-safe_print_list.py: Safely prints elements from a list.
- 1-safe_print_integer.py: Safely prints an integer.
- 2-safe_print_list_integers.py: Prints only integers from a list.
- 3-safe_print_division.py: Safely performs division.
- 4-list_division.py: Divides list elements safely.
- 5-raise_exception.py: Raises a custom exception.
- 6-raise_exception_msg.py: Raises an exception with a message.
- 100-safe_print_integer_err.py: Handles integer printing with error output.
- 101-safe_function.py: Executes a function safely.
- 102-magic_calculation.py: Advanced exception handling logic.

## Technologies Used

- Python 3
- Ubuntu Linux

## Concepts Practiced

- try / except blocks
- TypeError, ValueError handling
- Custom exception raising
- Defensive programming
- Error output management (stderr)
