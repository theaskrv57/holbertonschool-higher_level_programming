# Python Inheritance

This project focuses on understanding Object-Oriented Programming (OOP) concepts in Python, particularly inheritance and class relationships.

## Project Overview

The tasks in this directory explore:

- Class creation and object inspection
- Type checking
- Instance verification
- Inheritance relationships
- Method overriding
- Abstract base class concepts
- Building structured class hierarchies

The goal of this project was to develop a deeper understanding of how Python handles class inheritance and polymorphism.

## Files Description

- 0-lookup.py: Returns the list of available attributes and methods of an object.
- 1-my_list.py: Defines a class that inherits from list.
- 2-is_same_class.py: Checks if an object is exactly an instance of a specific class.
- 3-is_kind_of_class.py: Checks if an object is an instance of a class or inherited class.
- 4-inherits_from.py: Determines inheritance relationships.
- 5-base_geometry.py: Defines a base geometry class.
- 6-base_geometry.py / 7-base_geometry.py: Extends base class functionality.
- 8-rectangle.py: Implements a rectangle class inheriting from base geometry.
