# SQL Introduction

This project covers fundamental SQL concepts including:

- Creating and deleting databases
- Creating tables
- Inserting data
- Querying records
- Using aggregate functions
- Grouping results
- Filtering data

## Files Description

- 0-list_databases.sql: Lists all databases.
- 1-create_database_if_missing.sql: Creates a database if it does not exist.
- 2-remove_database.sql: Removes a database if it exists.
- 3-list_tables.sql: Lists all tables in a database.
- 4-first_table.sql: Creates the first table.
- ...
- 16-no_link.sql: Final task related to constraints.
