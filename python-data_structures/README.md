# Python Data Structures

This project focuses on mastering Python data structures and core programming concepts.

## Project Overview

The tasks in this directory cover:

- Lists manipulation
- Tuples operations
- Indexing and slicing
- Replacing and deleting elements
- Iteration techniques
- Conditional filtering
- Matrix printing
- Basic algorithmic logic

The goal of this project was to strengthen problem-solving skills and gain deeper understanding of how Python handles mutable and immutable data types.

## Files Description

- 0-print_list_integer.py: Prints all integers of a list.
- 1-element_at.py: Retrieves an element at a specific index.
- 2-replace_in_list.py: Replaces an element in a list.
- 3-print_reversed_list_integer.py: Prints a list in reverse order.
- 4-new_in_list.py: Replaces element without modifying original list.
- 5-no_c.py: Removes specific characters from a string.
- 6-print_matrix_integer.py: Prints a matrix of integers.
- 7-add_tuple.py: Adds two tuples.
- 8-multiple_returns.py: Returns multiple values.
- 9-max_integer.py: Finds the maximum integer in a list.
- 10-divisible_by_2.py: Checks divisibility conditions.
- 11-delete_at.py: Deletes element at given position.
- 12-switch.py: Swaps variable values.
