# RESTful API Implementation

This project focuses on building and interacting with RESTful APIs using Python, including basic security mechanisms.

## Project Overview

The tasks in this directory explore:

- Sending HTTP requests programmatically
- Implementing a simple HTTP server
- Building a REST API using Flask
- Handling routes and JSON responses
- Implementing basic authentication/security mechanisms
- Understanding client-server architecture

The objective of this project was to understand how modern web applications communicate through APIs and how backend services are structured.

## Project Structure

- task_02_requests.py: Sending HTTP requests using Python.
- task_03_http_server.py: Implementing a basic HTTP server.
- task_04_flask.py: Building a REST API using Flask framework.
- task_05_basic_security.py: Implementing basic API security concepts.

## Technologies Used

- Python 3
- Flask
- HTTP Protocol
- JSON
- REST Architecture

## Key Concepts Practiced

- REST principles
- API design
- Request/response lifecycle
- JSON data exchange
- Basic authentication mechanisms
- Backend security awareness
