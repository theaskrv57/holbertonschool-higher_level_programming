# Python Server-Side Rendering

This project focuses on building dynamic web content using server-side rendering techniques in Python.

## Project Overview

The tasks in this directory explore:

- Dynamic HTML rendering
- Template engines (Jinja)
- Conditional logic in templates
- File-based data rendering (JSON / CSV)
- Database interaction
- Backend-driven content generation
- Basic testing of rendered pages

The objective was to understand how backend applications generate dynamic web pages and interact with structured data sources.

## Project Structure

- templates/: Contains HTML templates used for rendering.
- task_00_intro.py: Basic server-side rendering example.
- task_01_jinja.py: Template rendering using Jinja.
- task_02_logic.py: Conditional rendering logic.
- task_03_files.py: Rendering content from JSON/CSV files.
- task_04_db.py: Database-driven rendering.
- create_database.py: Script for database setup.
- products.json / products.csv / items.json: Sample datasets.
- test_items_page.py: Basic test implementation.

## Technologies Used

- Python 3
- Jinja2
- SQLite (or relational DB)
- JSON / CSV
- HTML Templates

## Key Concepts Practiced

- Backend-rendered web pages
- Template engines
- Dynamic data injection
- Database connectivity
- Separation of logic and presentation
- Basic web application structure
