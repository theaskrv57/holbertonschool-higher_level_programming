# Python Import & Modules

This project focuses on understanding how Python modules work and how to structure reusable code across multiple files.

## Project Overview

The tasks in this directory cover:

- Importing functions from other Python files
- Working with built-in modules
- Using command-line arguments (sys.argv)
- Creating modular programs
- Writing simple calculators
- Executing scripts from the terminal
- Bytecode (.pyc) understanding

The objective was to learn how to build modular and maintainable Python programs.

## Files Description

- 0-add.py: Imports and uses a function to perform addition.
- 1-calculation.py: Performs multiple arithmetic operations.
- 2-args.py: Prints command-line arguments.
- 3-infinite_add.py: Adds arguments passed via command line.
- 5-variable_load.py: Imports a variable from another module.
- 100-my_calculator.py: Simple CLI calculator.
- 101-easy_print.py: Prints text without using print().
- 102-magic_calculation.py: Recreates bytecode logic in Python.
- 103-fast_alphabet.py: Optimized alphabet printing.

Supporting modules:
- add_0.py
- calculator_1.py
