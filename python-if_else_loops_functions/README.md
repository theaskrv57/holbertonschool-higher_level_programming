# Python If/Else, Loops & Functions

This project focuses on mastering fundamental Python control flow and function design concepts.

## Project Overview

The tasks in this directory cover:

- Conditional statements (if / elif / else)
- Logical operators
- Looping structures (for, while)
- Working with ranges
- ASCII manipulation
- Function definition and return values
- Basic mathematical operations
- Algorithmic problem-solving (FizzBuzz)

The objective was to build a strong programming foundation and improve logical thinking skills.

## Files Description

- 0-positive_or_negative.py: Determines if a number is positive, negative, or zero.
- 1-last_digit.py: Prints the last digit of a number.
- 2-print_alphabet.py: Prints the alphabet in lowercase.
- 3-print_alphabt.py: Prints the alphabet except specific characters.
- 4-print_hexa.py: Prints numbers in hexadecimal format.
- 5-print_comb2.py / 6-print_comb3.py: Prints formatted number combinations.
- 7-islower.py: Checks if a character is lowercase.
- 8-uppercase.py: Converts string to uppercase.
- 9-print_last_digit.py: Extracts and prints last digit.
- 10-add.py: Adds two integers.
- 11-pow.py: Computes power of a number.
- 12-fizzbuzz.py: Implements the FizzBuzz algorithm.
- 100-print_tebahpla.py: Prints alphabet in reverse order.
- 101-remove_char_at.py: Removes a character at a given index.
