# Python More Classes

This project focuses on advanced Object-Oriented Programming (OOP) concepts in Python through incremental class development.

## Project Overview

The tasks in this directory involve building and progressively improving a Rectangle class while implementing:

- Class attributes and instance attributes
- Data validation using property decorators
- Method overriding
- Custom string representation (__str__)
- Official object representation (__repr__)
- Static and class methods
- Instance tracking
- Encapsulation principles

Each file represents a step-by-step enhancement of the Rectangle class.

## Files Description

- 0-rectangle.py: Defines an empty Rectangle class.
- 1-rectangle.py: Adds width and height attributes.
- 2-rectangle.py: Implements area and perimeter methods.
- 3-rectangle.py: Adds string representation.
- 4-rectangle.py: Adds official representation (__repr__).
- 5-rectangle.py: Adds deletion behavior.
- 6-rectangle.py: Tracks number of instances.
- 7-rectangle.py: Adds customizable print symbol.
- 8-rectangle.py: Implements static method for comparison.
- 9-rectangle.py: Adds class method for square creation.
