# Python Networking & HTTP Requests

This project focuses on interacting with web servers using Python and understanding HTTP communication.

## Project Overview

The tasks in this directory explore:

- Sending HTTP requests
- Handling HTTP responses
- Working with status codes
- Sending POST requests
- Handling JSON APIs
- Authentication with GitHub API
- Extracting headers from responses
- Error handling in network communication

The objective was to understand how Python applications interact with web services and APIs.

## Files Description

- 0-hbtn_status.py: Fetches and displays HTTP response content.
- 1-hbtn_header.py: Retrieves specific HTTP headers.
- 2-post_email.py: Sends POST request with email parameter.
- 3-error_code.py: Handles HTTP error codes.
- 4-hbtn_status.py: Uses urllib for HTTP request.
- 5-hbtn_header.py: Retrieves headers using requests module.
- 6-post_email.py: Sends POST request using requests.
- 7-error_code.py: Improved error handling.
- 8-json_api.py: Sends JSON request and parses response.
- 10-my_github.py: Authenticates using GitHub API.
- 100-github_commits.py: Retrieves recent commits via GitHub API.

## Technologies Used

- Python 3
- requests library
- urllib
- JSON
- GitHub API

## Key Concepts Practiced

- HTTP methods (GET, POST)
- Status code handling
- API authentication
- JSON parsing
- Network error handling
