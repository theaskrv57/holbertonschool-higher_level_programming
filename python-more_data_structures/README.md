# Python More Data Structures

This project focuses on advanced usage of Python data structures including sets, dictionaries, and functional programming techniques.

## Project Overview

The tasks in this directory explore:

- Set operations
- Dictionary manipulation
- Lambda functions
- map() usage
- Filtering and transformation techniques
- Aggregation logic
- Basic algorithm implementation (Roman numerals, weighted averages)

The objective of this project was to improve efficiency in handling collections and strengthen problem-solving skills using Python.

## Files Description

- 0-square_matrix_simple.py: Squares values in a matrix.
- 1-search_replace.py: Replaces values in a list.
- 2-uniq_add.py: Adds unique integers in a list.
- 3-common_elements.py: Finds common elements between sets.
- 4-only_diff_elements.py: Finds symmetric difference of sets.
- 5-number_keys.py: Counts dictionary keys.
- 6-print_sorted_dictionary.py: Prints dictionary sorted by keys.
- 7-update_dictionary.py: Updates dictionary values.
- 8-simple_delete.py: Deletes key from dictionary.
- 9-multiply_by_2.py: Multiplies dictionary values.
- 10-best_score.py: Finds key with highest integer value.
- 11-multiply_list_map.py: Uses map() to multiply list elements.
- 12-roman_to_int.py: Converts Roman numerals to integers.
- 100-weight_average.py: Calculates weighted average.
- 101-square_matrix_map.py: Uses map() for matrix transformation.
- 102-complex_delete.py: Deletes keys with specific values.
