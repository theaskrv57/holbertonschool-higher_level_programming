# SQL More Queries

This project extends fundamental SQL knowledge by focusing on advanced queries, user privileges, constraints, and relational database operations.

## Project Overview

The tasks in this directory cover:

- Managing MySQL user privileges
- Creating and managing database users
- Applying constraints (NOT NULL, UNIQUE, FOREIGN KEY)
- Working with relational tables
- Subqueries and JOIN operations
- Aggregation and grouping techniques
- Real-world relational dataset queries (TV Shows database)

## Files Description

- 0-privileges.sql: Lists MySQL user privileges.
- 1-create_user.sql: Creates a MySQL user.
- 2-create_read_user.sql: Creates a user with read-only permissions.
- 3-force_name.sql: Enforces NOT NULL constraint.
- 4-never_empty.sql: Ensures field validation.
- 5-unique_id.sql: Implements UNIQUE constraint.
- 6-states.sql / 7-cities.sql: Creates relational tables.
- 8-cities_of_california_subquery.sql: Uses subqueries.
- 9-cities_by_state_join.sql: Uses JOIN operations.
- 10-genre_id_by_show.sql – 16-shows_by_genre.sql: Advanced relational queries on TV shows dataset.
- hbtn_0d_tvshows.sql: Dataset used for relational query practice.

## Technologies Used

## Key Concepts Practiced
